Installing Odoo 20 in Windows

Github Repository: https://github.com/jrgeralde/InstallingOdoo20Files


  1. Open the Odoo Project Folder in VSCode
  2. Check the odoo.conf
  3. Open the Terminal (use powershell)
  4. Create the virtual environment
    python -m venv venv
  5. Allow Scripts to run in VS Code Terminal (for First Open)
    Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
  6. Activate the virtual environment
    venv\Scripts\Activate.ps1
  7. Update pip and python package management
    python -m pip install --upgrade pip setuptools wheel
  8. Edit Line 53 of requirements.txt (Needed for Python 3.13 not for Python 3.12)
    from: rl-renderPM==4.0.3 ; to: rlPyCairo ;
  9. Install the odoo dependencies
    pip install -r requirements.txt
  10. Install qifparse Python dependency (For Cybrosys Accounting Kit)
    pip install qifparse
  11. Create the Database (in the terminal, github repo)
    .\createdb.ps1
  12. Run the odoo server
    python odoo-bin -c odoo.conf
